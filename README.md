# CSC584-Individual-Assignment-1
Personal Profile Web Application for CSC584 Individual Assignment 1

A) Project Description

This project is a simple Personal Profile Web Application developed for CSC584 Individual Assignment 1. It allows users to enter their personal information through an HTML form and displays the submitted information on a JSP page.

B) Technologies Used
- HTML
- Java Servlet
- JavaServer Pages (JSP)
- CSS
- GlassFish Server
- NetBeans IDE 8.2

C) Features
- Collects personal information through an HTML form.
- Processes submitted data using Java Servlet.
- Displays personal information using JSP.
- Provides a simple and user-friendly interface.

D) How to Run
1. Open the project in NetBeans IDE 8.2.
2. Make sure GlassFish Server is configured and running.
3. Right-click the project and select Run.
4. The application will open in a web browser.
5. Fill in the personal information and click Submit Profile.
6. The submitted information will be displayed on the profile page.

E) Required Software
- NetBeans IDE 8.2
- GlassFish Server
- Java Development Kit (JDK)
